How I work

You work with the person writing the code.

I like straightforward solutions and systems that are easy to understand later. I can work on both the code and the server it needs to run on, so a small project doesn't have to be split between three different people.

I'm especially interested in smaller projects, debugging, modernization, integrations, and odd technical problems that might not be worth taking to a large agency.
