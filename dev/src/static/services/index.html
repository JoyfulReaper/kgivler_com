Introductory rates

A few ways I can help

These services are currently $75/hour for agreed, in-scope work. I'll discuss the problem and the likely time involved before starting. Hourly billing isn't a promise that every problem can be solved in a set number of hours. Larger or less predictable work gets its own quote.

.NET Debugging & Troubleshooting

$75/hour — introductory rate

Help diagnosing crashes, exceptions, build problems, unexpected behavior, and configuration issues in C# and ASP.NET Core applications.

  • Review relevant code, logs, and reproduction steps
  • Investigate the likely cause and explain findings
  • Suggest a fix or implement an agreed, bounded change

A diagnosis doesn't guarantee a fix. Larger repairs or rewrites are scoped separately.

Linux VPS & Self-Hosting Help

$75/hour — introductory rate

Setup and troubleshooting for a Linux server or self-hosted service you control.

  • systemd, Docker/Compose, reverse proxies, and HTTPS
  • Service configuration, deployments, and connectivity issues
  • Backups, monitoring, and practical troubleshooting

Production changes require an agreed plan and your approval. No emergency response, 24/7 support, uptime guarantee, or blanket security certification is included.

Automation & Small Utilities

$75/hour — introductory rate

Small scripts, command-line utilities, scheduled jobs, and integrations that save repetitive work.

  • Automate a clearly described manual task
  • Move or process data between files or services
  • Document how to run and maintain the result

We'll agree on the inputs, outputs, and boundaries first. Large integrations and full applications are quoted separately.

Code Review & Technical Guidance

$75/hour — introductory rate

An outside look at a project, confusing piece of code, tests, or a technical decision you're trying to make.

  • Focused review of an agreed area of code
  • Practical feedback and next steps
  • Optional walkthrough or debugging session

This isn't a comprehensive security audit or a guarantee that every issue in a codebase will be found.
